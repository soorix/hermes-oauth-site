Hermes

A personal Google Workspace client — single user, not a public service.

What this is

Hermes is a private desktop automation client that runs on the owner's own macOS machine. It connects to Google Workspace APIs on behalf of exactly one person — the account owner — so that the owner can read and send their own mail, keep their own calendar, and open their own documents, spreadsheets and Drive files from a command line and a local dashboard.

Who uses it

One person: the project owner. There is no sign-up, no user accounts, no multi-tenant access, and no third-party customers. The application is not distributed as a service.

Google data it requests

Only what the owner's own workflows need, and only after the owner grants consent on Google's own screen: Gmail (read, send, modify labels — used for mail triage and for setting Gmail filters), Calendar, Drive (read-only), Sheets, Docs (read-only) and Contacts (read-only). What happens to that data is described in the privacy policy.
