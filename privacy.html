Privacy policy — Hermes

Effective 2026-10-20. Applies to the personal Hermes Google Workspace client described on the home page.

1. Who this covers

Hermes is used by a single person, the owner of the Google Account that grants it access. No other person's Google data is accessed, and the application is not offered to the public as a service.

2. What Google user data is accessed

  • Gmail (read, send, modify): to search and read the owner's own mail, send mail the owner asks it to send, and apply labels or filters.
  • Google Calendar: to read and create events on the owner's own calendars.
  • Google Drive (read-only): to locate files the owner points it at.
  • Google Sheets: to read and update spreadsheets the owner owns.
  • Google Docs (read-only): to read document bodies the owner asks about.
  • Contacts (read-only): to resolve names and addresses the owner refers to.

3. How the data is used

Data is used only to carry out the task the owner requests on their own machine — for example "summarise the mail from this sender", "move these messages into a label", "create this event". It is not used for advertising, profiling, analytics, model training, or any purpose the owner did not ask for.

4. Storage and retention

OAuth credentials are stored locally on the owner's computer, in the owner's user profile directory, with file permissions restricted to that user. Content that is processed is held in memory or in local working files for as long as the task needs it. Nothing is copied to a server operated by a third party, and there is no cloud database of user content.

5. Sharing

Google user data is not sold, rented, transferred, or disclosed to any third party, advertiser, or data broker. It is not shared with other people. The only external calls made are to Google's own APIs (for the features above) and to the model providers the owner has personally configured for their own use.

6. Revoking access

The owner can revoke this application's access at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token immediately; deleting the local token file removes it from the machine.

7. Limited Use statement

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes and contact

Material changes to this policy will be reflected on this page with a new effective date. Questions: soorix@gmail.com
